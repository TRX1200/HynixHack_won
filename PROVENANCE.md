# Package provenance

Version 2.0.0 retains the reviewed public v1.2.0 workbench core and its original MIT license.
The original v1.1.0 archive SHA-256 was
`1cf232f98b221e7fe11bcafb25edb6557e83437a9adbba8d638fd5c207e2b6ab`.
The public v1.2.0 source archive SHA-256 was
`f6588e253239c4c9b2e8bc12ab9c40435ffabacdc8d85f9278e98fbddba00ab1`.

The new inventory was adapted from a user-supplied public-candidate seed: 90 generic
recipe cards, 29 structural rules, 16 advisory code patterns and 16 synthetic profiles.
Routing, validation, fallback behavior, public documentation and tests were reviewed and revised.
Seven minimal executable example families, strict validation-plan generation and local
restart notes were added or integrated. The reference archive was not wholesale merged.

Only reviewed software, generic documentation, templates and synthetic examples are distributed.
Private operating guides, screenshots, personal recollections, handoff packets, actual
assessment statements/data/answers, credentials and live work logs are excluded.
Local generated test logs and browser credentials are not distributed.

Original kit works and the reviewed additions follow the retained MIT LICENSE. External
libraries and UI/MCP projects are references, not vendored assets; their own licenses and
runtime requirements still apply. Public availability is not organizer approval.
