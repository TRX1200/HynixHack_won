# wb-visualize

## 적용 경계
- 현장 규정·과제 요구·기존 프로젝트가 우선이다. 이 Skill은 추가 권한을 부여하지 않는다.
- 원본 보존. 외부 AI 호출·작업자료 외부 전송·자동 화면조작·관리 설정 변경 금지.
- 코드로 수행한 일과 지침만 작성한 일을 구분한다. 미실행 검사를 통과로 적지 않는다.
- 기존 Codex 버전을 유지한다. 의존성은 필요한 것만, 허용된 설치 경로에서 사용한다.
- 키트 위치는 `__KIT_ROOT__`. 미치환 상태이면 `tools/run.py`와 `docs/TOOLS.md`가 함께 있는 원본 키트 루트를 확인한다. 복사된 Skill의 상위 프로젝트를 키트로 추정하지 않는다.
- 문서·양식·예제 경로는 키트 루트 기준이다. 명령은 실제 확인한 실행기에서만 수행한다.
- Python이 없어도 Markdown 지침을 읽을 수 있다. Python 기능은 보류하고 기존 과제 언어·설치된 도구를 우선한다. 필요한 설치는 Helper/호스트의 허용 방법을 확인한다.


## 절차
1. 질문을 고정한다: 변화, 비교, 분포, 관계, 오차 중 무엇인가? 먼저 답할 질문을 적는다.
2. 입력 행과 실제 독립 실험 단위를 구분하고 결측·제외·정규화·분모를 기록한다.
3. 시간 변화는 선, 범주 비교는 점/막대, 분포는 histogram/box/ECDF, 관계는 scatter를 후보로 선택한다.
4. SD/SE/CI/예측구간을 혼동하지 않는다. 방법과 표본단위를 모르면 임의 error bar를 만들지 않는다.
5. Matplotlib는 PNG/SVG, Plotly는 JS를 포함한 자체완결 HTML을 우선 후보로 둔다. 외부 CDN·폰트·analytics 없이 열리는지 확인한다.
6. 바 차트의 잘린 축, 로그축의 0/음수, 숨겨진 결측, 자동 smoothing, 반복표본의 독립 취급을 점검한다.
7. 대표 수치를 원본/별도 계산과 대조한다. 보기 좋은 그림은 분석 타당성의 증거가 아니다.
## 완료 산출물
입력 데이터 경로/해시, 그래프 코드, 이미지/HTML, 축·단위·집계·불확실성 정의, 실제 확인한 항목.
렌더링을 확인하지 못하면 그 사실을 남긴다. 이미지는 코드를 통한 정량 시각화이지 AI 이미지 생성이 아니다.
