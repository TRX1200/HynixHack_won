# wb-physics

## 적용 경계
- 현장 규정·과제 요구·기존 프로젝트가 우선이다. 이 Skill은 추가 권한을 부여하지 않는다.
- 원본 보존. 외부 AI 호출·작업자료 외부 전송·자동 화면조작·관리 설정 변경 금지.
- 코드로 수행한 일과 지침만 작성한 일을 구분한다. 미실행 검사를 통과로 적지 않는다.
- 기존 Codex 버전을 유지한다. 의존성은 필요한 것만, 허용된 설치 경로에서 사용한다.
- 키트 위치는 `__KIT_ROOT__`. 미치환 상태이면 `tools/run.py`와 `docs/TOOLS.md`가 함께 있는 원본 키트 루트를 확인한다. 복사된 Skill의 상위 프로젝트를 키트로 추정하지 않는다.
- 문서·양식·예제 경로는 키트 루트 기준이다. 명령은 실제 확인한 실행기에서만 수행한다.
- Python이 없어도 Markdown 지침을 읽을 수 있다. Python 기능은 보류하고 기존 과제 언어·설치된 도구를 우선한다. 필요한 설치는 Helper/호스트의 허용 방법을 확인한다.


## 절차
1. 요구 물리량과 관측량을 구분한다. 기호표에 단위·좌표·부호·시간 convention을 적는다.
2. 적용 법칙과 가정, 초기/경계조건, 파라미터 출처, 유효 범위를 원문과 가정으로 분리한다.
3. 차원을 점검한다. SI/단위 변환, Hz vs rad/s, deg vs rad, amplitude vs power, peak vs RMS를 명시한다.
4. SymPy는 식 정리/미분/적분/잔차 후보, NumPy/SciPy는 수치 계산, Pint는 단위 점검 후보로 쓴다.
5. 기호해는 원래 식과 조건에 다시 대입한다. 단위가 맞는다는 이유만으로 모델이 맞다고 결론내리지 않는다.
6. 경계값·0/무한대 극한·대칭·보존법칙 중 적용 가능한 검사를 실제로 수행한다.
7. 수치해는 tolerances/격자/시간간격 변화, 다른 방법 또는 해석해 비교로 확인한다. solver success와 물리 정확성은 다르다.
8. 파라미터가 식별 가능한지, 데이터가 부족한지, 모형 불확실성과 측정 오차가 어떻게 다른지 기록한다.
9. 불확실한 특수공식은 기억으로 채우지 않는다. 허용된 자료에서 원문을 확인하고 적용 가정을 밝힌다.
## 검증 예시
`__KIT_ROOT__/tools/numeric_smoke.py`: 합성 RC 1차 시스템의 기호 잔차·초기조건·수치해를 해석해와 비교한다.
이 테스트는 RC 예제만 확인하며 임의 물리 문제의 정답을 보장하지 않는다.
