# wb-graphics

## 적용 경계
- 현장 규정·과제 요구·기존 프로젝트가 우선이다. 이 Skill은 추가 권한을 부여하지 않는다.
- 원본 보존. 외부 AI 호출·작업자료 외부 전송·자동 화면조작·관리 설정 변경 금지.
- 코드로 수행한 일과 지침만 작성한 일을 구분한다. 미실행 검사를 통과로 적지 않는다.
- 기존 Codex 버전을 유지한다. 의존성은 필요한 것만, 허용된 설치 경로에서 사용한다.
- 키트 위치는 `__KIT_ROOT__`. 미치환 상태이면 `tools/run.py`와 `docs/TOOLS.md`가 함께 있는 원본 키트 루트를 확인한다. 복사된 Skill의 상위 프로젝트를 키트로 추정하지 않는다.
- 문서·양식·예제 경로는 키트 루트 기준이다. 명령은 실제 확인한 실행기에서만 수행한다.
- Python이 없어도 Markdown 지침을 읽을 수 있다. Python 기능은 보류하고 기존 과제 언어·설치된 도구를 우선한다. 필요한 설치는 Helper/호스트의 허용 방법을 확인한다.


## 절차
1. 산출물을 분류한다: 실제 관측 사진, 이미지 주석, 개념도, 데이터 그래프, 장식용 이미지.
2. 실제 관측 자료는 생성물로 대체하지 않는다. 그림에 실제/모의/개념 중 무엇인지 표시한다.
3. 별도 이미지 생성 API·사전학습 가중치를 연결하지 않는다. 호스트의 명시적 허용 기능이 확인되지 않으면 Pillow/SVG 등 코드 기반 제작으로 범위를 정한다.
4. crop/resize/rotation의 원본 좌표 변환과 aspect ratio를 기록한다. 파일 목록과 처리 실패를 남긴다.
5. 결과 크기·잘림·텍스트 겹침·원본과의 대응을 확인한다. 사람이 제공 미리보기에서 확인하는 것과 자동 화면조작은 구분한다.
6. 이미지 분석은 기존 wb-vision과 결합한다. 차이 마스크를 결함 정답으로 부르지 않는다.
## 후보
Pillow: 크기 변경·자르기·주석·합성. SVG: 정확한 벡터 도식.
OpenCV/scikit-image: 정렬·윤곽·영역 측정(딥러닝 가중치 없이 가능한 처리부터).
## 검증
정상 입력, 조명/정렬만 변한 정상 입력, 작은 합성 이상, 범위를 벗어난 crop을 구분해 테스트한다.
검사 이미지를 외부 서버로 보내지 않는다. 이미지 시각 읽기는 호스트에서 지원되는지 먼저 확인한다.
