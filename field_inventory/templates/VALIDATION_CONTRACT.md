# 작업별 검증 계약 — 빈 양식

이 파일은 일반적인 빈 양식이다. 현재 작업에 맞게 채운 사본은 허용된 로컬 작업 폴더에만 저장한다.
문제·원본 데이터·로그가 들어간 사본을 공개 저장소로 보내지 않는다.

- 필요한 결과와 실제 요구의 출처:
- 입력 범위·행/개체 단위·식별자·단위:
- 확인된 사실과 미확정 요구:
- 기대 출력·오류 처리·보존 조건:
- 선택한 방법과 적용·제외 조건:
- 검사의 독립성: 구현과 다른 계산, 작은 정답 사례, 원문 조건 등:

| 검사 ID | 요구와 출처 위치 | 독립 기대 기준 | 정상 합성 입력 | 반드시 실패해야 하는 입력 | 실행 명령 | 상태 | 로컬 근거 위치 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| CHECK-001 | | | | | | NOT_RUN | |

## 실행 후 채우기

- 실제로 읽은 입력의 범위와 해시/개수:
- 수행한 검사와 실패 건수:
- 수행하지 못한 검사와 영향:
- 실제 측정한 품질·시간·불확실성(해당할 때):
- 통과가 증명하지 않는 범위:
- 허용된 내부 미리보기 확인 여부:

검증 계획 생성은 검사 구현·실행을 대신하지 않는다. 실패 사례가 실제로 검출되는지 확인하고,
실제 근거가 없으면 `PASS`가 아니라 `NOT_RUN` 또는 `BLOCKED`로 남긴다.
