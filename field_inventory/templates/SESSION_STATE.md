# 로컬 작업 상태 — 빈 양식

빈 양식만 공개한다. 실제 경로·문제·입력·코드·운영 로그를 채운 사본은 허용된 작업 환경에만 둔다.

- 확인한 현재 작업 폴더:
- 원문 요구/코드 중 검토한 범위:
- 확인된 실행기와 버전:
- 마지막으로 통과한 작은 실행과 종료 상태:
- 변경한 파일과 아직 저장하지 않은 내용:
- 확인된 서버/프로세스 상태(필요할 때만):
- 미확정 조건과 현재 막힌 점:
- 아직 실행하지 않은 검사:
- 다음에 할 최소 행동 한 가지:
- 실제 기록 시각과 시간대:

재연결 후 실제 파일·저장 상태·프로세스를 확인하고 마지막 작은 검사를 다시 실행한다.
완료했다고 추정하거나 파괴적인 명령을 반복하지 않는다. 재연결은 제공된 도움말을 따르며
관리·승인·감독 설정이나 연결 프로세스를 바꾸지 않는다.
