# 사용 경계

이 저장소는 범용 지침·알고리즘·양식·로컬 검사 도구입니다. 특정 비공개 과제의 답안이 아닙니다.
사용 시 현장 최신 공지와 과제별 지시가 우선입니다. 이 문서는 운영진의 허가서가 아닙니다.

## 기본 정책
- 허용된 작업환경 안에서 입력을 읽고 출력을 저장합니다.
- 외부 AI 호출·개인 API 키·자동 모델 설치·Codex 업데이트 기능은 없습니다.
- 기본 Python 도구에는 웹/데스크톱 자동 클릭·키보드 조작·화면 캡처·원격 제어 기능이 없습니다.
- 기본 Python 도구에는 외부 파일 전송·telemetry·Git push·원격 배포 기능이 없습니다.
- 선택형 외부 MCP는 기본 도구와 별도로 검토합니다. OSS 라이선스만으로 모든 사용 방식이 허용되지는 않습니다.
- 공개 코드를 다운로드하는 것과 작업 내용을 외부에 보내는 것은 다릅니다.
- 공개 도구로 최종 산출물을 통째로 대체하지 않습니다. 이번 요구에 맞춘 판단·구현·검증이 필요합니다.
- 기존 AGENTS.md/호스트 설정을 지우거나 보안·승인·감독 기능을 변경하지 않습니다.
- 차단된 기능을 다른 도구·경로로 우회하지 않습니다. 허용된 도움말/문의 경로를 사용합니다.

## 공개 저장소 유지
평가에 사용한 공개 자료의 유지 기간은 해당 주최 측의 최신 규정에 따릅니다.
평가 중 다른 사람이 이 저장소를 바꿔 특정 답안이나 지시를 전달하는 용도로 사용하지 마십시오.
가능하면 준비 완료 버전의 commit ID를 기록하고 결과 통지 전까지 공개 접근 상태와 이력을 유지하십시오.
평가가 시작된 뒤에는 이 준비 저장소에 과제별 기능·설명·답안을 추가하거나 변경해 전달하지 않습니다.
그 단계의 문제 해결과 결과 작성은 허용된 제공 환경 안에서 수행합니다.

## 실제 문제 보호
시험 문제·개인 링크·감독 자료·안내 원문·비공개 데이터·본인 결과물·AI 대화 기록을 공개 저장소에 넣지 마십시오.
'.gitignore'는 보안 장치가 아니며 이미 추적한 파일의 공개를 막지 않습니다.
제공된 release manifest는 패키지 파일의 무결성 확인 수단이지 기밀 탐지나 법적 적합성 판정기가 아닙니다.

## 이해도 평가
AI가 허용되는 준비/과제 단계에서만 wb-explain을 사용합니다.
AI 금지 서술형/인터뷰 단계에는 모델, Skill, MCP를 이용해 답변을 만들지 않습니다.
직접 설명할 수 없는 결과는 직접 설명할 수 있는 것으로 기록하지 않습니다.
