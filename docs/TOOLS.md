# 실제 구현 도구와 한계

| 명령 | 기능 | 핵심 제한 |
|---|---|---|
| doctor | Python/선택 라이브러리 확인 | 모델·권한·네트워크·비밀키는 검사하지 않음 |
| calculate | 회로·공정 기초 공식의 단위 명시 계산 | 교육용 한정 모델; 식·가정·SI 단위는 ELECTRONICS_CALCULATORS_KO.md 확인 |
| inventory | 명시된 입력 폴더 파일 목록 | 숨김/의존성/심볼릭링크 제외; 메타데이터만 |
| csv-profile | 행·열·결측·중복키·수치 범위 | CSV/TSV; 결측은 빈값만; 숫자처럼 보이는 ID는 변환하지 않음 |
| join-audit | 키 중복·미매칭·예상 결합 행 수 | 실제 결합은 수행하지 않음; 빈 키끼리 매칭하지 않음 |
| aggregate | 그룹별 건수·유효건수·합·평균 | 정확 Decimal 합계(정렬 10,000자리 상한), 평균 28유효자리 half-even; 비수치/NaN/Inf 실패; 누락값은 0 아님 |
| extract | TXT/MD/CSV/JSON/PDF/DOCX 근거 색인 | PDF 선택 의존성; 표·읽기순서 시각 재검토; OCR 없음 |
| search/read-chunk | 원문 위치 포함 문자 검색·본문 조회 | 의미검색/BM25 아님; 스냅샷; 검색실패가 부재 증명은 아님 |
| check-evidence | 근거 필드·참조ID·유효일 형식 검사 | 사실성·모순 해결·원문 의미 검증 아님 |
| order | 선후관계의 가능한 순서·유일성·순환 여부 | 선택한 사전순은 업무 우선순위 아님; 차단 노드=정확한 순환 목록 아님 |
| assign | 작은 유한 배정 문제 완전탐색 | 항목별 단가/기능/허용선택/용량만; 할인·고정비·최소구매 미지원 |
| check-assignment | 배정 제약·총비용 재계산 | 잘못 모델링된 업무 조건은 별도 검토 |
| contact-sheet/crop/annotate | 이미지 목록·확대·표시 | 전문 결함 탐지 모델 아님; EXIF 정규화 좌표 |
| image-diff | 동일 크기 이미지 차이 마스크 | 정렬·조명 보정 없음; 투명 입력은 배경 합성 후 사용; 결함/정확도 판정 아님 |
| report | 입력 JSON을 Markdown/HTML로 정리 | 값 생성·사실 검증·문서 의미 교정 안 함 |
| check-manifest | 필수 파일·형식·텍스트·해시 확인 | 실제 제출 범위/내용 정답을 보증하지 않음 |

## 데이터 원칙
CLI와 MCP의 JSON 출력은 UTF-8입니다. 다른 프로그램에서 실행 결과를 읽을 때도 UTF-8로 디코딩합니다.
CSV는 기본 UTF-8 BOM 허용, cp949는 --encoding cp949로 명시합니다. 구분자는 --delimiter로 명시합니다.
헤더 중복/빈 이름/열 수 불일치는 자동 수정하지 않고 실패합니다.
줄이 아니라 CSV 레코드 번호를 오류 위치로 표시합니다(멀티라인 셀 가능).
가격의 콤마, 단위, 백분율은 자동 삭제하지 않습니다. 정책을 정해 전처리하고 원본을 보존하십시오.
JSON 중복 키와 표현 범위를 벗어나는 수는 거절합니다. CSV의 닫히지 않은 따옴표도 거절합니다.
집계 그룹명이 sum/mean/n_total 등 결과 필드와 충돌하면 임의 이름 변경 없이 중단합니다.
Decimal 평균은 무한정 정확한 값이 아니며, 지원 범위 아래로 0이 되는 underflow는 오류로 보고합니다.

## 자원 상한
입력 파일 64 MiB, CSV 250,000행, 이미지 40MP, contact sheet 80개, 추출 배치 200파일.
상한을 넘으면 명시적으로 중단합니다. 전체 처리한 척 부분 결과를 반환하지 않습니다.
큰 데이터는 본인 판단으로 분할·표본·스트리밍 도구를 선택하고 범위를 보고하십시오.

## 선택 의존성
Pillow 12.3.0 / PyMuPDF 1.26.7에서 테스트했습니다. 전체 환경 호환성을 보장하지 않습니다.
이 문장의 버전은 원본 검증 기록 기준입니다. 이번 수정본에서 실제 실행한 항목은 TEST_RESULTS.md를 확인하세요.
시험 제공 환경에 설치가 차단되면 우회하거나 Codex를 업데이트하지 않습니다.

## 설정 생성 도구
`python tools/mcp_config.py --index <기존 색인.jsonl> [--out <새 설정.json>]`은
현재 실행 중인 Python과 서버/색인의 실제 절대경로를 사용한 JSON을 출력합니다.
MCP를 등록하거나 실행하지 않으며, 빈 색인/잘못된 색인/기존 출력 덮어쓰기는 거절합니다.
호스트 UI의 기존 서버와 병합하고 실제 호출을 확인하세요. 자세한 순서는 docs/MCP.md를 따릅니다.

## 보고서 검증 항목
validation은 check/expected/actual/status/evidence를 가진 목록으로 작성합니다.
실행한 pass/fail에는 공백이 아닌 문자열 근거 경로/설명을 넣어야 합니다.
자유 문장 하나를 넣는 것만으로 검사 완료를 대신할 수 없습니다. 사실성은 별도 확인합니다.

## 배정 검사기의 독립성
check-assignment는 후보 생성과 분리해 호출할 수 있지만, solver도 같은 검사 함수를 사용합니다.
완전히 독립된 두 구현의 교차검증은 아닙니다. 원문 제약 대조와 작은 사례 손계산을 추가하십시오.
배정은 최대 50항목이며 계산량에 따라 실제 탐색 상한을 줄여 effective_max_states로 알립니다.
CSV는 최대 1000열/500만 셀 상한도 적용합니다.
